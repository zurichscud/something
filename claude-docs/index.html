Getting started

Overview

这是一份用于演示的文档页：完整还原 Claude 官方文档站的排版骨架，包括顶栏、分组侧边导航、正文与右侧目录。页面内容为示例文字，仅用于对照样式细节。

下面的内容覆盖标题层级、段落、列表、行内代码、多语言代码块、提示框与表格等常见元素，方便逐项比对颜色、字距与间距。

Get started

从终端、编辑器或桌面端任选一种方式开始。下面以终端为例，其余入口可以在标签页之间切换查看；代码块在悬停时会显示操作按钮。

# 初始化项目并启动本地预览
pnpm create fumadocs-app@latest java-docs
cd java-docs
pnpm dev --port 3000
// .vscode/settings.json
{
  "editor.formatOnSave": true,
  "files.exclude": { "**/.next": true }
}

桌面端提供独立窗口的工作流，适合长时间编辑与多项目切换，安装包可在官方下载页获取。

Web 版本无需安装，打开浏览器即可使用；登录后会话记录会与其余入口保持同步。

JetBrains 系列 IDE 可在插件市场搜索安装，安装完成后在侧边栏打开面板即可。

本页所有命令与路径均为示例文本，用于展示样式，不代表真实安装步骤。

What you can do

这份复刻页覆盖了阅读文档时最常出现的几类元素，改动样式时可以直接在这里逐项验证：

  • 排版：标题层级、段落、有序与无序列表、引用与表格。
  • 代码：行内代码、多语言语法高亮，以及悬停出现的复制按钮。
  • 导航：顶部分组标签、左侧分组导航与右侧 On this page 目录。
  • 主题：浅色与深色两套 token，支持一键切换并记忆偏好。

Use it everywhere

同一套样式可以复用到不同入口，下面这段 Java 代码用于检查代码块在浅色与深色下的配色：

public final class DocPage {
  private final String slug;

  public DocPage(String slug) {
    this.slug = slug;
  }

  public String url() {
    return "/docs/" + slug; // 生成文档链接
  }
}

引用块的文字颜色更浅，左侧有一条竖线，用于承载旁注或来源说明。
