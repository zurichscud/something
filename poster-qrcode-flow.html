涉及的外部依赖与数据

存储

  • MySQL 表 lpgs_user：字段 invited_qrcode、invited_poster （读：getInvitedQrcode / getInvitePoster；写：addUserInviteInfo 一次更新两个字段）
  • Redis key wechat_access_token：TTL 7000 秒，双检锁 + 40001 强制刷新
  • 阿里云 OSS：二维码 PNG 与海报 JPG 各上传一次，返回公网 URL

外部接口与组件

  • GET /wxa/getwxacodeunlimit：生成无限制小程序码（is_hyaline 透明底）
  • WeChatUtil.getAccessToken(appid, secret)：换取 access_token
  • 超时配置：connect 5000ms / socket 10000ms
  • PosterComposer + PosterProperties(prefix=app.poster)：海报模板与二维码位置

异常与返回分支

触发条件处理返回
invited_qrcode 与 invited_poster 均有值 短路返回，不调用微信、不合成海报 Result.success(Wxqrcode{qrcode, poster})（日志标记「数据库」）
两者之一为空 继续走完整生成流程（会覆盖原有值） 生成后由 addUserInviteInfo 同时回写两个字段
userId 为空或 <= 0 抛 IllegalArgumentException，被 catch(Exception) 捕获 Result.error("用户ID必须为正整数")
access_token 为空 抛 RuntimeException Result.error("获取微信AccessToken失败")
errcode = 40001（token 失效） 删除 Redis 旧 token，refreshAndGetToken 后重试 1 次 重试成功则正常返回，否则进入下一条
其他微信错误码 抛 WeChatApiException Result.error(errmsg)
海报模板未配置 / 读取失败 IllegalStateException("海报模板未配置，请检查 app.poster.template") Result.error(错误信息)
模板或二维码图片解析失败 / 海报编码失败 PosterComposer 抛 IllegalStateException Result.error(错误信息)，同时 log.error("生成二维码失败")
循环耗尽（重试 > 1 次） 退出 while Result.error("请求超过最大重试次数")
