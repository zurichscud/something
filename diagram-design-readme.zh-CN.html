架构差异对比图（Architecture delta） 通过同步拓扑结构对比，展示“演进前（Before）· 变更分类账 · 演进后（After）”，清晰呈现增、删、改、移及重连对象。单纯属性数值对比保留使用普通表格；单个静态切面架构直接使用通用架构图（Architecture）。

轴测爆炸图（Exploded axonometric） 采用 2:1 二等角投影，将单一实体部件以均等间距沿轴线分解展开：例如手机拆解、开箱陈列、应用架构栈、AI 智能体分层栈或机械键盘结构。全部坐标源于单一数学投影函数，动效版本初始呈组装状态并进行单次爆炸展开演示。

轴测平面图（Axonometric plan） 采用相同投影方式刻画单层空间或园区场景：墙体按桌面高度剖切，以便从单一视角纵览所有房间；或用于呈现按建设阶段标记的园区规划。

品牌入驻适配（Onboarding）—— 让图表具备你的专属品牌风格

核心意义在于：输出采用属于你的色彩与字体的出版级图表，而不是千篇一律的通用模板。

开箱即用状态下，图表采用干净利落的深黑 + 原子橙（jet-black + atomic-tangerine）配色方案（烟白底色、墨黑线条、原子橙强调色、暗石板灰辅助色与银色细线）。直接截图就已经非常精美。但仅需 60 秒的初始化入驻，技能就会直接读取你的网站，提取品牌基因应用到所有图表中。

交互流程

你：   "onboard diagram-design to https://yoursite.com"
Agent： → 抓取你的网站主页
        → 提取主色调、调色板及字体栈
        → 将检测到的属性映射为语义 Token：
            paper（底色）, ink（墨水/主字色）, muted（弱化色）, accent（主强调色）, link（链接色）
        → 展示拟变更的对比差异 (Diff)
        → 将设计 Token 写入 references/style-guide.md
你：   "yes, apply it"

自动对比度检验

在写入 Token 之前，技能会针对 paper 上的 ink 执行 WCAG AA 对比度验证。如果网站某个颜色在图表尺寸（9–12px）下对比度不足，它会自动提议微调后的合规数值并说明原因。

默认开箱即具备无障碍支持（a11y）

每个内联 SVG 均带有 role="img"、解析关联的 aria-labelledby 以及首位子级 <title> / <desc> 槽位。ID 按图表和变体加前缀，多张图表在同一页面内联也不会发生 ID 冲突。

核心四维调节维度 (The four dials)

重点不是粗暴的文件格式转换，而是契合不同交付场景的最佳呈现形式：

调节维度 可选参数 产生的改变
格式 (Format) html · svg · png · html+png 最终交付载体。SVG 用于 Figma，PNG 用于幻灯片，HTML 用于 Web 发布。
尺寸 (Size) doc-inline · doc-wide · slide-16x9 · slide-4x3 · social-og · social-square · print-a4-landscape · fit 调整 viewBox 与字体阶梯 —— 幻灯片投影模式节点字号放大至 16px，而非文档内嵌的 12px。
精细度 (Detail) faithful (≤24 节点) · balanced (≤12) · simplified (≤7) 保留源节点层级的梯队规则：优先剔除纯装饰，其次合并副本与叶子节点簇，最后精简基础设施。
受众 (Audience) engineer (研发) · mixed (通用) · executive (管理层) 影响文本表述的颗粒度而非单纯节点数。例：Auth Service / JWT · RS256 · :8443 → Auth Service / token check → Sign-in (登录)。

每次导入最后都会输出一份精确度账单 (Fidelity ledger)，详细列出合并、折叠或删减了哪些要素，一目了然。

设计系统核心原则（一览）

单一强调色，每张图仅设 1–2 个焦点元素。三种字体系列：Instrument Serif（标题与斜体引导说明）、Geist sans（节点名称正文字体）、Geist Mono（技术附属标签）。1px 极细发丝级边框，无浮夸投影，最大圆角限 10px。所有坐标、尺寸、边距间距必须能被 4 整除 —— 这是图表脱离“廉价 AI 生成质感”的关键所在。等宽字体仅用于严格的技术语义（端口、URL、字段类型），杜绝滥用所谓 Geek 程序员风。

基础图元组件 (Primitives)

  • 注释题注 (Annotation callout) —— 斜体 Instrument Serif 字体配合虚线贝塞尔引线，用于边缘出版风格的额外补充注记。
  • 手绘风格滤镜 (Sketchy filter) —— 基于 SVG 湍流（turbulence）与置换贴图（displacement map）实现的自然手绘波纹，适合文稿插图。
  • 专用图标集 (Icon set) —— 包含 87 款单色 IT/云计算专用图标（笔记本、手机、用户、服务器、数据库、Docker、Kubernetes、AWS、GitHub、Postgres 等），统一继承 currentColor，可无缝跟随主题色调渲染。

何时不应该使用本技能

  • 发推特或命令行纯终端输出的字符画 → 请使用类似 wiretext 的字符工具。
  • 罗列信息条目的清单列表 → 直接使用标准 Markdown 表格或无序列表。
  • 简单的 Before / After 对比 → 使用左右双列表格更加直观。
  • 只有单个方块加标签的所谓“图” → 直接写成一句话即可，不要画图。

动手绘图前请思考：读者从这张图中获取的信息，是否比直接阅读一段结构精炼的文字更多？如果不是，请不要画图。
