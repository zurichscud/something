接入要点

        
    
            
  1. 后端引入 captcha-spring-boot-starter，配置 aj.captcha.*；starter 只提供
                CaptchaService，/captcha/get、/captcha/check 需要自己暴露（见
                CaptchaController）。
    2. 
            
  2. 前端引入 verify.js（依赖 jQuery 与 crypto-js），调用
                $('#id').slideVerify({...}) 或 $('#id').pointsVerify({...})。
    3. 
            
  3. 验证成功后前端拿到 captchaVerification，随业务请求提交，后端用
                captchaService.verification(vo) 校验，校验一次即失效。
    4. 
            
  4. 单机用默认内存缓存；多实例部署需实现 CaptchaCacheService（SPI）接入 Redis，
                否则生成与校验可能落到不同实例。

常见问题（FAQ）

        

            
底图和拼图块是从哪来的？

            
滑动底图（310×155）、拼图块（47×155）、点选底图（310×155）都取自 AJ-Captcha 官方仓库的 demo 工程
                service/springboot/src/main/resources/images；页面的 js / css / 字体来自官方
                view/html 目录。都是原样拷贝，没有改动。


            
能换成自己的图片吗？

            
能。滑动底图用任意照片裁成 310×155；拼图块是 47×155 的透明 PNG，高度必须等于底图高；
                点选底图裁成 310×155。改 aj.captcha.jigsaw、aj.captcha.pic-click 指向自己的目录即可。


            
右下角的“我的水印”是图片自带的吗？

            
不是。那是依赖在每次 /captcha/get 时用 Java2D 画上去的：白色、字号约 12、固定在右下角。
                改文字用 aj.captcha.water-mark，去掉就把它设成空值。
